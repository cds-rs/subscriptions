# DSL test reports

Execution snapshots of the subscriptions integration suite, run through the anchor-litesvm World/scenario DSL. Each `#[test]` writes one report here; each report reads a single transaction five ways: the structured CPI tree, the sequence diagram (with and without lifelines), and the authority and ownership graphs, plus the narrative steps and `check` rows.

**220 reports** across **16 instructions**, grouped by category below and sorted within each. The actors are deterministic and the clock is pinned, so the reports are byte-reproducible: regenerate them with `cargo test -p tests-subscriptions` (they land here via `MD_REPORTS_DIR`, set in `.cargo/config.toml`).
